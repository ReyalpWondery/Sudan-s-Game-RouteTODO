# 苏丹的游戏 · 线路规划器

> 单机游戏《苏丹的游戏》（Sultan's Game）的纯前端路线规划器 —— 把错综复杂的任务线理成一张清晰的 TODO 清单。

## ✨ 功能一览

- **📋 任务线 TODO**：按篇章（人物线 / 主线 / 基础篇）把任务线加入清单，跟踪每个事件的完成 / 锁定 / 排除状态
- **🔓 自动解锁**：完成事件后，自动解锁并加入后续线路，「当前可做」列表实时汇总
- **🔀 分歧处理**：抉择点选了一个分支，同线的其他分支自动打删除标，不再干扰规划
- **🃏 销卡查询**：查询任意一张卡（尤其四品级苏丹卡：杀戮 / 纵欲 / 奢靡 / 征服）能去哪些事件销掉、哪些未完成任务需要保留它
- **⚠️ 冲突预警**：同类型同品级苏丹卡被过多未完成事件必需时，顶部自动警告
- **🏆 成就跟踪**：成就清单与篇章、事件互相关联，完成进度一目了然
- **💾 本地存档**：进度保存在浏览器 `localStorage`，关掉页面也不丢

## 🚀 快速开始

无需安装、无需构建、无需服务器：

```
直接用浏览器打开 planner/index.html
```

数据全部内联，双击即用，也支持任意静态托管部署。

## 🛠 技术栈

- 原生 HTML + CSS + 浏览器端 JavaScript（ES5 风格），零框架、零构建、零运行时依赖
- 唯一的第三方依赖是 `jsdom`，仅用于测试
- 无网络请求、无遥测，纯静态页面

## 🧪 测试

测试基于 Node + jsdom，在真实 DOM 上跑整个应用：

```bash
cd planner/.test
npm install            # 只装 jsdom（首次或 package-lock 变化后）
node smoke.js          # 冒烟测试：添加线路、解锁链、撤销、持久化
node features_test.js  # 销卡查询页等特性
node branch_test.js    # 分歧自动排除逻辑
node savestate_test.js # 存档/完结标记
node achv_test.js      # 成就页
node followup_test.js  # 完成事件后自动加入后续线路
```

## 📁 目录结构

```
├── data/                  # 源数据（JSON，人工整理的游戏攻略数据）
│   ├── chapters/          #   43 个篇章文件
│   ├── achievements.json  #   成就
│   └── cards_*.json       #   卡牌图鉴（4 个分片）
└── planner/               # Web 应用本体
    ├── index.html         #   单页入口
    ├── data.js            #   生成的数据文件（由 data/ 下的 JSON 生成）
    ├── app.js             #   主逻辑
    ├── cardpage.js        #   销卡查询页
    └── .test/             #   Node + jsdom 测试
```

> 修改攻略数据请改 `data/` 下的源 JSON，并同步重新生成 `planner/data.js`（详见 `AGENTS.md`）。
